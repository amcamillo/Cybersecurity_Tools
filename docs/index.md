# Cybersecurity Tools

This site is a work-in-progress catalog for finding defensive resources, authorized security-testing references, detection engineering material, research, and demos.

## Catalog legend

| Color | Focus |
| --- | --- |
| **Blue** | Prevention, monitoring, response, and recovery |
| **Red** | Authorized security testing and adversary emulation |
| **Green** | Threat intelligence, sharing, and research |
| **Purple** | Collaboration between offensive testing and defensive validation |

Browse the [color catalog]({{ '/catalog/' | relative_url }}), [detection engineering]({{ '/detection-engineering/' | relative_url }}), [AI security]({{ '/ai-security/' | relative_url }}), [architecture]({{ '/architecture/' | relative_url }}), [community tools]({{ '/community-tools/' | relative_url }}), [demos]({{ '/demos/' | relative_url }}), or [advisories]({{ '/advisories/' | relative_url }}).

Every catalog entry should link to its repository, publisher, or official documentation. Unlinked claims and invented tool URLs do not belong here.
