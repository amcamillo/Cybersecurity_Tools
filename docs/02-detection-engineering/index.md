# Detection Engineering

Detection engineering turns threat hypotheses into versioned, testable analytics. Start with a behavior, identify the required telemetry, write a query, test expected positive and negative cases, and document operational response.

- [KQL]({{ '/detection-engineering/kql/' | relative_url }})
- [CQL]({{ '/detection-engineering/cql/' | relative_url }})
- [Splunk SPL]({{ '/detection-engineering/splunk/' | relative_url }})

Use [MITRE ATT&CK](https://attack.mitre.org/) as a vocabulary for behaviors and coverage, not as a substitute for testing against local data.
