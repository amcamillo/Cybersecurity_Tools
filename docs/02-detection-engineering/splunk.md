# Splunk Search Processing Language (SPL)

- [Splunk Search Reference](https://docs.splunk.com/Documentation/Splunk/latest/SearchReference/WhatsInThisManual)

Build searches against documented source types and normalized fields. Check time bounds, cardinality, acceleration assumptions, and false-positive handling before converting a search into a scheduled alert or correlation search.
