# CrowdStrike Query Language (CQL)

- [CrowdStrike LogScale query-language syntax](https://library.humio.com/data-analysis/syntax.html)

CQL examples depend on the event source, parser, and field schema. Verify field names and query cost against the destination LogScale or Falcon environment, and test detections with known data before enabling alerts.
