# Green

Green-team resources support threat intelligence, research, and knowledge sharing.

- [MISP](https://www.misp-project.org/) — an open-source threat-intelligence sharing platform.
- [MITRE ATT&CK](https://attack.mitre.org/) — a common knowledge base for adversary behavior.
- [CISA Known Exploited Vulnerabilities Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) — evidence-based vulnerability prioritization input.
- [Repository research](https://github.com/amcamillo/Cybersecurity_Tools/tree/main/Research) — research artifacts maintained in this repository.

Treat shared intelligence as potentially sensitive. Validate provenance, confidence, handling restrictions, and expiration before operational use.
