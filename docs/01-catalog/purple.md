# Purple

Purple teaming connects controlled adversary emulation to observable defensive outcomes.

- [MITRE ATT&CK](https://attack.mitre.org/) — map hypotheses, behaviors, and coverage using a shared vocabulary.
- [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) — run reviewed, authorized tests and compare expected telemetry with collected evidence.
- [MITRE Caldera](https://caldera.mitre.org/) — orchestrate controlled emulation in a lab or explicitly approved environment.
- [Detection engineering]({{ '/detection-engineering/' | relative_url }}) — turn observed behavior into testable queries and detections.

Define scope, safety controls, expected telemetry, rollback, and success criteria before testing.
