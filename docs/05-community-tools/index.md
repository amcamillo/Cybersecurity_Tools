# Community Tools

Community-maintained projects can provide open formats, shared knowledge, and reproducible security validation.

- [MISP](https://www.misp-project.org/) — threat-intelligence sharing and workflows.
- [MITRE ATT&CK](https://attack.mitre.org/) — community-informed knowledge of adversary tactics and techniques.
- [Atomic Red Team](https://github.com/redcanaryco/atomic-red-team) — portable tests for controlled validation.
- [MITRE Caldera](https://caldera.mitre.org/) — automated adversary emulation for authorized environments.

Before adopting a project, review its maintainers, release history, license, documentation, security policy, and operational impact. Use testing tools only within an approved scope.
