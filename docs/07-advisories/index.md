# Worldwide Advisories

This section is reserved for exceptional, worldwide-impact security events that require coordinated action across many organizations, such as Log4j-class events. It is intentionally not a CVE feed or vulnerability dump.

An entry should include:

1. authoritative advisory and vendor sources;
2. affected technology and exposure conditions;
3. defensive detection and mitigation guidance;
4. key updates with dates; and
5. a clear review or archival state.

For routine exploited-vulnerability prioritization, use the [CISA Known Exploited Vulnerabilities Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog).
