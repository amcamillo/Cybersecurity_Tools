# AI Security

The repository groups AI security material into two broad areas:

- [AI threat research](https://github.com/amcamillo/Cybersecurity_Tools/tree/main/AI/ThreatsResearch) collects research notes and referenced threat artifacts.
- [AI security methodology](https://github.com/amcamillo/Cybersecurity_Tools/tree/main/AI/Methodology) collects methodology notes, governance guides, and prompt-injection material.

Start at the [AI directory](https://github.com/amcamillo/Cybersecurity_Tools/tree/main/AI) for the complete repository tree. Some methodology resources are PDFs or spreadsheets; this site links to them without rewriting the binary archives.
